Main feature

- Disable trade wind (could be toggle)

- Add slider to control wind direction change magnitude, wind change timer and wind speed changing speed.

Value explained

- Direction Chaos: Bigger means wind direction could change more drastically.

- Larpspeed bigger: Bigger means wind change speed faster. Game calculate gust at 0.5 sec timer, so if this value is high you will experience very abrupt and unstable wind speed change. Will also change how fast the wind settle in new direction.

- Larpspeed slider is disabled as default. You need to toggle it on before using it.

- Timer: Number you set will be average timer. Actual timer range from 0.5x of the value to 2x of the value to set. For example a minimal value of 2 means wind change every 1~4 second. 

- New timer will be applied after current timer is done, so you might need to wait for a while.

- if wind stuck after changing value, restart will usually fix it.

This mod doesn't modify wind speed.

Note: This mod is compatible with Climate mod's wind stability function, since it change different value. For maximum random, set Wind stability to 0 and Direction Chaos to 1
